# ▶️ Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/react-learning.git
```

Navigate into the project:

```bash
cd react-learning
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
